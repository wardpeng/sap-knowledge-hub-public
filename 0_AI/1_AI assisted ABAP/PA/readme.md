# SAP PA认证两种形式说明

SAP 的 PA（Practical Assessment，实操评估）目前可分为两类：

1. **System-based assessment**（系统实操评估）
2. **Scenario-based assessment**（场景式评估）

本文根据 SAP 官方 FAQ 整理为中文，便于快速理解两类考试的区别与注意事项。

官方来源：

- [Scenario-based assessment FAQs](https://learning.sap.com/helpcenter/certification-support/scenario-based-assessment-faqs)
- [System-based assessment FAQs](https://learning.sap.com/helpcenter/certification-support/system-based-assessments-faq)

---

## 1. System-based assessment（系统实操评估）

### 1.1 形式特点

这类考试更偏向**在真实或准真实 SAP 系统中完成指定任务**。不是口头问答，而是要求你进入系统，按任务说明完成操作。

### 1.2 如何开始

入口同样有两个：

- 在认证详情页点击 **Go to Certification Exam**
- 在 Learning Journey 中点击 **Open**

开始前同样需要：

- 有有效的认证考试次数
- SAP Universal ID 配置正确

考试页通常会显示：

- 本次考试是否包含 system-based 或 scenario-based assessment
- 完成考试的准确时长
- 当前认证和订阅剩余次数

点击 **Start the Certification Exam** 后，考试正式开始并进入倒计时。

### 1.3 材料在哪里下载

要查看并下载安装指南、认证任务和课程文件，官方给出的步骤是：

1. 先给予 Consent
2. 在 `System Based Assessment` 窗口点击 **Enroll**
3. 下载相关材料

通常可以获得：

- setup guide（环境或系统准备指南）
- certification task（考试任务）
- course files（课程相关文件）

### 1.4 Enroll 后多久能进入系统

官方说明：

- 系统注册或准备通常只需要**几分钟**
- 某些系统可能会更久一些

### 1.5 如何完成考试

官方给出的完整流程大致如下：

1. **Enroll and prepare the system**
   - 点击 **Enroll** 准备考试系统
   - 某些练习系统可能立即可用
   - 某些系统则需要预约一个时间段（reserve a slot）
   - 预约时间段**不算一次考试 attempt**
   - 如果无法参加，可以重新预约其他时间
   - 确认后通常会收到邮件，以及考试前 24 小时提醒邮件
2. **Review setup instructions and tasks**
   - 在考试页查看 setup guide 和 certification tasks
3. **Access the system**
   - 点击 **Access System**
   - 系统会在新标签页打开
   - 可以同时保留考试页面和系统页面
4. **Complete and confirm the certification tasks**
   - 完成任务后，在 assessment 页面点击确认完成
   - 官方说明结果通常会在几秒内显示

### 1.6 时间与中断规则

system-based assessment 的时间规则比较严格：

- 开始后计时器立即运行
- 可以中途休息
- **但休息不会暂停计时**
- 必须在**同一次 session** 中完成全部任务
- 不能暂停后改天继续

也就是说，这类考试本质上是一次性完成型实操考试。

### 1.7 成绩何时公布

官方 FAQ 中有两种表述：

- 一处说明：确认完成后进入审核，**通常约 15 分钟**
- 另一处说明：在完成并确认后，结果会在**几秒内显示**

可以理解为：

- 正常情况下系统会较快给出结果
- 若进入审核流程，则可能需要更长一点时间

成绩可在 **My Learning - Certifications** 中查看。

### 1.8 常见失败原因

官方列出的常见原因包括：

- 活动时限到期（activity limit expired）
- 没有达到通过分数

如果订阅中还有剩余 attempt，可以重新安排新的考试。

### 1.9 技术问题处理

如果出现以下问题，官方建议先做基础排查：

- 页面加载慢
- 白屏
- 页面显示异常

建议操作：

- 清理浏览器缓存和 cookies
- 刷新页面或重启浏览器
- 更换浏览器
- 检查网络连接

如果在考试过程中遇到技术问题，导致无法完成任务，应提交 support case，并尽量提供：

- 问题详细说明
- 复现步骤
- 截图

如果 SAP 确认属于系统侧问题，**可能会补发新的考试机会**。

### 1.10 点击 Confirm 后还能不能再进系统

不能。

官方说明：

- 一旦点击 **Confirm**
- 本次考试即结束
- 不能再次进入系统
- 所有浏览器会话都应立即关闭

## 2. Scenario-based assessment（场景式评估）

### 2.1 形式特点

这类考试更偏向**情境问答、角色模拟、口头表达**，用于验证考生是否真正理解业务场景与相关概念。

官方说明中，这类评估支持两种完成方式：

- **AI-guided option（推荐）**
  - 通过 AI 引导式的虚拟面试进行。
  - 系统会提出贴近真实工作的场景问题，并记录你的回答。
  - 完成后可获得个性化反馈。
- **Human reviewer**
  - 按页面提示录制视频并上传。
  - 由 SAP 评审人员审核。
  - 提交后需要先校验视频，再发布结果。
  - 官方说明该流程**可能需要最多 20 个工作日**。

### 2.2 如何开始

可以从两个入口进入考试：

- 在认证详情页点击 **Go to Certification Exam**
- 在 Learning Journey 中点击 **Open**

开始前需要满足：

- 有有效的认证考试次数（valid certification attempt）
- SAP Universal ID 已正确配置

进入考试页后，通常可以看到：

- 当前考试是否包含 scenario-based 或 system-based assessment
- 可用考试时间
- 当前认证及订阅剩余考试次数

点击 **Start the Certification Exam** 后，倒计时会立即开始。

### 2.3 首次启动时要做什么

第一次启动 scenario-based assessment 时，通常需要：

- 允许麦克风权限
- 选择是否启用摄像头
- 接受 cookies

完成后点击 **Start** 开始。

### 2.4 成绩查看与 AI 评分方式

提交前，你可以先选择 **Save and view analysis** 查看分析结果和详细分数。

官方对 AI 评分的说明重点包括：

- AI 不只是匹配关键词，而是判断你回答的**语义意图（semantic intent）**
- 每个考试目标会根据专家设定标准，按 **1 到 5 分**评分
  - 1 = Insufficient
  - 5 = Excellent

### 2.5 时间与暂停规则

- 点击开始后，**总倒计时立即启动**
- 可以点击暂停按钮暂停 AI 角色互动
- **但暂停不会停止考试总计时**
- 可以中途休息，但休息时间同样会消耗考试时间

因此，这类考试虽然支持中途停一下，但本质上仍然要在总时限内完成。

### 2.6 如果没有通过

官方 FAQ 说明：

- 如果本次 scenario-based assessment 没通过，但**总计时还没结束**，可以立即重考
- 在这种情况下，**只算一次考试 attempt**
- 同一认证考试在 **12 个月内最多可参加 4 次**
- 两次考试之间必须间隔 **24 小时**
- 如果 4 次都未通过，则需要在最后一次考试后等待 **1 年**才能再次参加

### 2.7 语言支持

官方页面说明 scenario-based assessment 支持多语言，包含中文、英语、德语、法语、日语、韩语、西班牙语等。考试开始前，可在练习或预览界面左下角的 **Language** 菜单切换语言。

如果切换语言后仍显示错误语言，官方建议：

- 完全重启浏览器
- 确认英文在浏览器语言偏好中位于较高优先级
- 清理浏览器缓存后再试

### 2.8 常见技术问题

如果公司网络或防火墙导致考试无法启动，官方建议：

- 先尝试切换到家庭 Wi-Fi 或手机热点
- 若切换网络后恢复正常，则大概率是公司网络限制导致
- 联系 IT 或网络管理员放行相关地址

官方页面提到的相关地址包括：

- `*.yoodli.ai`
- `storage.googleapis.com`

### 2.9 获取帮助

考试进行中如果需要帮助，可以在 SAP 支持入口提交 case，并选择：

- `Scenario Based Assessment` 作为服务类别

建议在说明中尽量提供：

- 问题现象
- 触发步骤
- 截图

## 3. 两类 PA 的核心区别

| 维度 | System-based assessment | Scenario-based assessment |
|---|---|---|
| 核心形式 | 进入 SAP 系统完成实际任务 | 场景问答、角色模拟、口头或视频作答 |
| 主要能力 | 系统操作、配置与实操能力 | 业务理解、表达、情境分析 |
| 作答方式 | 在指定系统中执行任务 | AI 引导面试或录制视频 |
| 设备要求 | 浏览器 + 可访问考试系统 | 麦克风，通常可选摄像头 |
| 计时规则 | 可休息，但总计时不停 | 可暂停互动，但总计时不停 |
| 是否必须一次完成 | 是，必须单次 session 内完成 | 基本是 |
| 出分方式 | 系统确认后快速出分或进入审核 | AI 分析或人工审核 |
| 特别注意点 | 系统预约、材料下载、系统访问稳定性 | 网络、防火墙、音视频权限 |

## 4. 备考建议

### 对 System-based assessment

- 提前下载并阅读 setup guide 和 task 文件
- 尽早完成 Enroll，避免临近开考才发现系统未就绪
- 如需预约 slot，尽早确认时间
- 操作完成前不要急于点 Confirm

### 对 Scenario-based assessment

- 提前测试麦克风、摄像头、浏览器权限
- 熟悉英文或中文界面切换
- 练习用结构化方式回答业务场景题
- 注意控制时间，因为暂停不会停表

---

## 5. 一句话总结

- **System-based assessment**：更像“在真实系统里完成任务的上机实操”
- **Scenario-based assessment**：更像“场景化口试 / AI 面试”

如果你准备的是 SAP PA 认证，通常需要先确认该认证对应的是哪一种 practical exam，再针对性准备。
